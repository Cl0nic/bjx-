# Mini Cloud Storage ☁️

Hi! I'm 13 years old, and this is my first cloud project. 

It's a Python CLI that works like a mini Amazon S3. It uses a local JSON file as a database to store files and validates them by format.

## 🚀 Features
*   **Upload**: Add files (only `.png` allowed).
*   **Download**: Read file contents.
*   **Delete**: Remove files.
*   **List**: See all files in the storage.

## 🛠 Tech Stack
*   **Python 3**
*   **JSON** (database)

## ⚙️ How to run
```bash
python ct.py
